# Fashion Item Recognition – Mini-Project

This mini-project uses Deep Learning and Convolutional Neural Networks (CNNs) to classify clothing images from the Fashion-MNIST dataset.

## Models
- Fully Connected Neural Network
- Convolutional Neural Network (CNN)

## Technologies
- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Pandas
- Google Colab

## Outputs
- Trained models
- Model comparison
- Prediction gallery
- Misclassification analysis
